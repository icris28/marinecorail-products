# Marine Corail - Catalogue Sea-Doo & Can-Am

Prototype v0.1 basé sur 5 fiches techniques fournies.

## Modifier facilement
- `vehicles.js` : caractéristiques techniques
- `prices.js` : prix en F CFP TTC
- `inventory.js` : actif/inactif, statut, quantité, couleur

## Ajouter un véhicule
Dupliquer une entrée dans `vehicles.js`, lui donner un `id` unique, puis ajouter le même id dans `prices.js` et `inventory.js`.

## Masquer un véhicule
Dans `inventory.js`, mettre `active:false`.

## GitHub Pages
Mettre tous les fichiers à la racine du dépôt.
